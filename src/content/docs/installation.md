## Prerequisites

### Window XP & Vista

Download and install:

*   <a href="https://s3.amazonaws.com/factorbi/bipost/WindowsInstaller-KB893803-v2-x86.zip" target="_blank">Windows Installer.</a>
*   Prerequisites for Windows 7 and 8.

### Windows 7 and 8

For most Windows 7 and up there is no need to install the prerequisites. Nevertheless if you face any trouble running biPost.exe, please try with the following.

*   <a href="https://s3.amazonaws.com/factorbi/bipost/dotNetFx40_Full_x86_x64.zip" target="_blank">Microsoft .NET Framework 4</a>
*   <a href="https://s3.amazonaws.com/factorbi/bipost/vcredist_x86.zip" target="_blank">Microsoft Visual C++ 2010</a>
*   <a href="https://s3.amazonaws.com/factorbi/bipost/VFPOLEDBSetup.zip" target="_blank">Visual FoxPro OLEDB</a> <-- Only for DBF connection.

## Download & Install

1.  <a href="https://s3.amazonaws.com/factorbi/bipost/biPost.zip" target="_blank">**Download latest version here.**</a>
2.  Unzip **biPost.zip** to any folder on your Windows.
3.  Run **biPost.exe**
4.  Configure synchronization for [SQL Server](/sqlserver), [Firebird](/firebird) or [dBase](/dbase)
